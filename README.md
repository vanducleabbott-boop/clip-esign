# clip-esign

Build app **Clip** (https://github.com/rileytestut/Clip, giấy phép Unlicense) thành IPA không ký để cài qua ESign.
Workflow lấy thẳng mã nguồn gốc mỗi lần chạy, áp các bản vá trong `va/*.patch` (nếu có).

- **Phiên bản**: file `PHIEN_BAN` = `<phiên bản> <số build>`. Bản gốc của Riley = `1.2 1`.
  Mỗi lần sửa lỗi / thêm tính năng: **nâng phiên bản** (1.3, 1.4…) và số build (+1).
- IPA ra `Clip_v<phiên bản>.ipa` → chép vào `G:\My Drive\zalocall\Clip\` (kèm bản `Clip.ipa` = bản mới nhất).
